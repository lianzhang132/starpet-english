# v1.8.1 · 首次公开源码发行

本次将现有星伴英语 1.8.1 整理为可自行部署的开源项目。

## 包含

- HarmonyOS 4.2 兼容 APK 的 Java 原生层、内置学习界面及自动检查。
- FastAPI / SQLite 学习服务、私有 whisper.cpp 识别容器及模型下载校验脚本。
- 14 个视频、433 条合成英语音频、素材来源、许可及署名。
- 保留的 ArkTS 原生工程，尚未完成编译和真机验收。
- 中文 README、部署与构建说明、MIT 许可证、第三方许可及贡献指南。

## 与私人试用部署的区别

公开源码使用占位服务地址，不含私人部署域名、学习数据、录音、签名密钥、模型权重或内部运维历史。自行部署后修改 `config/deployment.json`，导出配置并重建 APK。

Release 中的 `offline-demo.apk` 仅用于体验内置课程、故事和宠物。默认不提供在线同步或跟读识别；需要这些功能时请自行部署并构建。该 APK 为内部试用签名，不保证与其他发行来源使用相同签名，不能承诺覆盖安装保留数据。

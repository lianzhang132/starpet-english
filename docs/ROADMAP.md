# 星伴英语完善路线图

以中文母语小学生能够持续、轻松地听懂并主动开口为目标。先完善可靠性和学习闭环，再扩充内容与面向更多家庭的能力。每个阶段的工作以可观察的行为验收，未完成真人或设备检查时不标记为完成。

## 1. 跟读可信与不挫败

**已有：**主动录音、回放、取消、网络失败保留本次录音重试、私有识别服务与温和反馈。

**本轮开发：**识别没听懂时不降低已有口语掌握度，不把它计入口语掌握度的错误次数；自动复习和宠物对同一话题的主动邀请推迟一天，孩子仍可马上手动重练。已能听懂时，仍按原本到期时间判断是否提升复习间隔。家长报告的到期数遵守同一推迟时间。

**继续完成：**

- [ ] 在家长自愿配合下，用真实儿童短句、轻声、停顿、背景噪声和词语遗漏复测新识别引擎；记录识别准确率和等待时间，不保存原声或识别文本作为默认行为。
- [ ] 优化长等待的明确状态、取消与重试体验；低置信度或服务异常不冒充孩子的发音错误。
- [ ] 将家长报告中「尝试过」「识别听懂」与「选择题答对」分开统计；当前汇总正确率仍包含语音识别结果，不能视为孩子的发音准确率。
- [ ] 试听字母音、单词、句子及不同角色声音；先验证少量样例，再批量更换语音。

验收：用户能听见示范、主动录音和回放；重复点击、取消、切页、断网及超时不造成旧结果、重复奖励或麦克风残留。真人复测结果与自动测试分开记录。

## 2. 每天有清楚的学习路径

- [ ] 将字母与拼读、故事重点句、生活口语和已有间隔复习串成「听懂 → 模仿 → 换场景使用」。
- [ ] 划分听过、理解过、尝试说过、识别听懂和延迟复习通过，避免把听过当成掌握。
- [ ] 明确展示今天的新内容与复习原因；完成当天计划后提供自由重练，避免相同概念反复强推。
- [ ] 建立按能力递进的短课程和词汇表，用真实儿童使用反馈调整难度。

验收：已熟悉且未到复习时间的内容不自动重复；看过的故事无需重看即可做待完成的题；学习过的表达能在另一生活场景练习。

## 3. 让波波陪伴而不打扰

- [ ] 丰富可通过学习和互动获得的装扮、动作、小任务和表情，不用饥饿或惩罚迫使孩子回来。
- [ ] 增加家长可配置的安静时段、暂停邀请和稍后再说；主动邀请与当前学习阶段相关。
- [ ] 在实际平板上验证后台运行、锁屏、低电量、系统回收、耗电和温度；尊重系统权限及用户关闭选择。

验收：应用前台不插话；拒绝后不持续打扰；关闭后不自行恢复；长时间运行行为通过设备实测。

## 4. 家长管理与数据恢复

- [ ] 家长报告以可理解的学习行为及下一步建议为主，区分识别不确定与明确答错。
- [ ] 添加学习时长与休息提示，并允许家长调整；避免将时长等同于学习效果。
- [ ] 设计多儿童档案、家长入口保护、换机恢复、账户与设备所有权校验；保留已有单设备进度，明确冲突处理。
- [ ] 完成后端访问控制、限流、监测、异地备份与独立恢复演练，按实际业务核对儿童隐私和上架要求。

验收：断网和升级后不丢记录；恢复演练在独立数据副本完成；不同孩子的数据不会互相覆盖。

## 5. 内容与发行

- [ ] 按分级目标增加有明确授权的趣味英语故事，保留创作者、许可证和改编说明，并经亲子试听评估。
- [ ] 视频改为少量内置、按需下载和可管理的离线缓存，处理空间不足、断网续传、内容撤回和版本更新。
- [ ] 继续维护当前 HarmonyOS 4.2 兼容 APK；分别完成 HarmonyOS 5+ 原生工程的构建、签名、设备及上架验证。
- [ ] 根据真实家长需求评估可持续经营方式；付费流程需要家长确认、订单恢复与清晰退款说明。

验收：内容可追溯且在目标设备上可播放；更新与回退不会清除学习数据；正式发布前完成真实用户和设备测试。

## 已知边界

- 当前 14 个视频只是第一批，不代表完整商业级视频库；示范音仍以合成为主。
- 本轮规则不会追溯修改历史掌握度。旧版本客户端可能无法保留新增的复习推迟字段，混用版本前需要验证迁移。
- 自动测试不能证明儿童语音识别准确性、声音自然度、学习效果或长期留存。
- 当前随机设备标识不是完整认证，公开部署需先补齐访问控制。
